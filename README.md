# Syntecxhub_Hand_Gesture_Recognition

This project is part of the **Syntecxhub Artificial Intelligence Internship Program**. It implements a real-time Hand Gesture Recognition system using Python, OpenCV, and MediaPipe.

## Features
- Real-time hand landmark detection using MediaPipe[cite: 7].
- Gesture classification (e.g., Open Palm, Fist)[cite: 7].
- Live webcam demo with bounding boxes and visual feedback[cite: 7].
